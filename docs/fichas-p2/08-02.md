## Fontes (ids a criar; se algum já existir no fontes.json, reaproveite e some os fatos na observação)

### `qgis-intro-vetor` — QGIS Documentation 3.44, "A Gentle Introduction to GIS — Vector Data". URL: https://docs.qgis.org/3.44/en/docs/gentle_gis_introduction/vector_data.html
- "Vector data provide a way to represent real world features within the GIS environment. A feature is anything you can see on the landscape." (casas, estradas, árvores, rios.)
- "Vector features have attributes, which consist of text or numerical information that describe the features."
- "A vector feature has its shape represented using geometry. The geometry is made up of one or more interconnected vertices. A vertex describes a position in space using an X, Y and optionally Z axis."
- Um só vértice: feição de **ponto**. Dois ou mais vértices, com o primeiro diferente do último: **polilinha** (linha). Três ou mais vértices, com o último igual ao primeiro: **polígono** (área fechada).
- Exemplo do manual: os atributos de um ponto dizem, por exemplo, "if it is a tree or a lamp post".

### `qgis-intro-raster` — QGIS Documentation 3.44, "A Gentle Introduction to GIS — Raster Data". URL: https://docs.qgis.org/3.44/en/docs/gentle_gis_introduction/raster_data.html
- "Rasters are made up of a matrix of pixels (also called cells), each containing a value that represents the conditions for the area covered by that cell."
- Raster serve para informação contínua sobre uma área, que não se divide bem em feições vetoriais; exemplos: imagens de satélite e fotografias aéreas.

### `qgis-tabela-atributos` — QGIS User Guide 3.44, "Working with the Attribute Table". URL: https://docs.qgis.org/3.44/en/docs/user_manual/working_with_vector/attribute_table.html (versão 4.x em desenvolvimento: mesma página em /testing/)
- "Each row in the table represents a feature (with or without geometry), and each column contains a particular piece of information about the feature." Coluna = campo ("each column a field").
- O QGIS carrega camadas espaciais e tabelas não espaciais (sem geometria); as não espaciais aparecem e se editam na mesma tela de tabela de atributos.
- Abrir: **Layer ► Open Attribute Table**, botão **Open Attribute Table** da barra Attributes, ou **F6**. **Shift+F6** abre só as feições selecionadas. Igual na 3.44 e na 4.x.
- O título da tabela mostra o total de feições da camada e quantas estão selecionadas ou filtradas.
- No canto inferior esquerdo da tabela há uma lista de filtros de exibição: **Show All Features**, **Show Selected Features**, **Show Features Visible on Map**.
- Modos de ver: **Table view** (uma linha por feição) e **Form view** (uma feição por vez).
- **Diferença na 4.x** (manual "testing", conferido em 10/11/2026): "Double clicking the row header will zoom to the feature in the map canvas (if the layer has geometry)." Essa frase não está no manual da 3.44.

### `qgis-abrir-dados` — QGIS User Guide 3.44, "Opening Data" (já criada na lição 08-03; some estes fatos na observação). URL: https://docs.qgis.org/3.44/en/docs/user_manual/managing_data_source/opening_data.html
- Formatos vetoriais citados pelo manual: GeoPackage, GML, GeoJSON, GPX, KML, CSV, Shapefile, DXF, entre outros.
- Abrir camada vetorial: **Layer ► Add Layer ► Add Vector Layer…** (Ctrl+Shift+V) ou o **Data Source Manager** (Ctrl+L), que reúne num só lugar arquivos e bancos de dados. Raster: **Layer ► Add Layer ► Add Raster Layer…** (Ctrl+Shift+R).
- Painel **Browser**: mostra as pastas e os "contêineres" de camadas, como um GeoPackage; dá para expandir o arquivo, ver as camadas dentro dele e pôr no projeto arrastando ou com duplo clique.
- Tudo isso é igual na 3.44 e na 4.x.

### `qgis-ferramentas-gerais` — QGIS User Guide 3.44, "General Tools". URL: https://docs.qgis.org/3.44/en/docs/user_manual/introduction/general_tools.html (igual na 4.x)
- **Identify Features**: **View ► Identify Features** (Ctrl+Shift+I) ou o botão na barra Attributes; depois clicar numa feição (ou pixel) da camada ativa: abre uma janela com as informações dela.
- No painel **Layers**, o menu de contexto da camada tem **Show Feature Count** (mostra o número de feições ao lado do nome).

## Pontos de conceito que a lição deve deixar claros (todos cobertos pelas fontes acima)

- Camada = um conjunto de feições do mesmo tipo de geometria (poste = ponto; cabo e vão = linha; quadra = polígono). Não misture: CEO/CTO são pontos, o cabo é linha.
- A geometria diz ONDE e a forma; os atributos dizem O QUÊ. Apagar uma linha da tabela apaga a feição (é o mesmo objeto) — diga apenas "a linha da tabela e o desenho no mapa são o mesmo objeto"; não descreva edição (é assunto da lição 08-05).
- Raster é imagem em pixels (satélite, foto aérea): serve de fundo; não tem "poste" clicável com tabela.
- Tabela sem geometria existe e é normal (ocupantes).
- Uma linha tem comprimento; um ponto não. Para saber o comprimento de um cabo, a camada tem de ser de linha. (Não entre em como medir: é a lição 08-06.)
