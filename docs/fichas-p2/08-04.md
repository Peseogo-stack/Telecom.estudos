## Fontes

### `gdal-kml` — GDAL, driver "KML - Keyhole Markup Language" (documentação; organização: GDAL/OSGeo). URL: https://gdal.org/en/stable/drivers/vector/kml.html
- "KML by specification uses only a single projection, EPSG:4326. All OGR KML output will be presented in EPSG:4326. As such OGR will create layers in the correct coordinate system and transform any geometries."
- KML é uma linguagem baseada em XML para exibir dados geoespaciais; é padrão OGC.

### `gdal-shapefile` — GDAL, driver "ESRI Shapefile / DBF". URL: https://gdal.org/en/stable/drivers/vector/shapefile.html
- Um shapefile é um conjunto de arquivos: `.shp`, `.shx` e `.dbf` formam uma camada; o SRC vem do `.prj`, quando existe.
- "Shapefile feature attributes are stored in an associated .dbf file, and so attributes suffer a number of limitations: Attribute names can only be up to 10 characters long." Nomes repetidos depois do corte ganham número (exemplo do manual: abcdefghijkl → abcdefgh_1).
- Tipos de campo aceitos: inteiro, real, texto e data ("not DateTime, just year/month/day").
- Texto mais longo que a largura do campo é truncado.
- "it is not recommended to use a file size over 2GB for both .SHP and .DBF files."
- Uma camada por shapefile ("treated as a dataset with one layer").

### `gdal-gpkg` — GDAL, driver "GPKG -- GeoPackage vector". URL: https://gdal.org/en/stable/drivers/vector/gpkg.html
- "The GeoPackage standard uses a SQLite database file as a generic container"; é um padrão OGC. (Com `qgis-abrir-dados`, já na base: um arquivo só, contêiner de várias camadas, que o painel Browser expande.)

### `gdal-csv` — GDAL, driver "Comma Separated Value (.csv)". URL: https://gdal.org/en/stable/drivers/vector/csv.html
- Sem arquivo de tipos (`.csvt`), "The OGR CSV driver returns all attribute columns as string data types".
- (Com a lição 08-03: o CSV não guarda SRC; quem abre informa o Geometry CRS.)

### `gdal-dxf` — GDAL, driver "AutoCAD DXF". URL: https://gdal.org/en/stable/drivers/vector/dxf.html
- "By default, the entire contents of the file are represented as a single OGR layer named "entities"." O nome da camada do desenho (layer do CAD) vira um campo chamado `Layer`.

### `qgis-abrir-dados` (já existe; some à observação) — QGIS User Guide 3.44, "Opening Data"
- "For DXF files containing several geometry types (point, line and/or polygon), the name of the layers will be generated as <filename.dxf> entities <geometry type>." Ou seja: o QGIS separa o DXF em camadas por tipo de geometria.
- Para manter a estrutura e a simbologia do desenho: **Project ► Import/Export ► Import Layers from DWG/DXF…**, que importa os elementos para um GeoPackage.
- Igual no manual da 4.x em desenvolvimento (conferido em 10/11/2026).

### `qgis-criar-camadas` (já existe; some à observação) — QGIS User Guide 3.44, "Creating Layers"
- Salvar em outro formato: botão direito ► **Export ► Save Features As…** (ou **Save Selected Features As…**, só as selecionadas). No diálogo: **Format**, **File name**, **Layer name** (quando o arquivo é um contêiner, como o GeoPackage) e **CRS** ("can be changed to reproject the data").

## Quadro que a lição deve montar (tudo coberto acima)

| Formato | O que é | Guarda SRC? | Cuidado |
| --- | --- | --- | --- |
| GeoPackage (`.gpkg`) | um arquivo só, contêiner de várias camadas (padrão OGC, banco SQLite) | sim | é o formato dos dados do exercício |
| Shapefile (`.shp` + outros) | vários arquivos para UMA camada | sim, no `.prj` | nome de campo com até 10 caracteres; mande TODOS os arquivos, não só o `.shp` |
| KML (`.kml`) | XML para o Google Earth e parecidos | sempre EPSG:4326 | ao exportar, as coordenadas são convertidas para graus |
| CSV (`.csv`) | texto com colunas | não | quem abre informa X, Y e o SRC (lição 08-03); as colunas vêm como texto se não houver arquivo de tipos |
| DXF (`.dxf`) | desenho de CAD | NÃO AFIRME (não conferi) — escreva "confira o SRC com quem desenhou" | o QGIS separa por tipo de geometria; a camada do CAD vira o campo `Layer` |

- NÃO diga qual formato é "o melhor" nem que o GeoPackage "substitui" o Shapefile. Diga o que cada um guarda e perde. Qual formato a empresa usa e exige do fornecedor: `{{confirmar}}`.
- "Google Earth" pode ser citado como exemplo de programa que lê KML (o manual da GDAL fala em "GeoBrowsers"); não afirme mais nada sobre ele.
- Segurança de dados: arquivo com a rede real da empresa não se manda por KML para fora nem se sobe em serviço on-line sem autorização: `{{confirmar}}` (uma linha).
