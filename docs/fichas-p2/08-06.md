## Fontes (reaproveite as que já existem no fontes.json e some os fatos na observação; crie as que faltam)

### `qgis-propriedades-vetor` — QGIS User Guide 3.44, "The Vector Properties Dialog" (Query Builder). URL: https://docs.qgis.org/3.44/en/docs/user_manual/working_with_vector/vector_properties.html (4.x em desenvolvimento: mesma página em /testing/)
- O **Query Builder** abre por **Layer ► Filter…** (na 3.44 o manual cita também o botão Query Builder na aba Source das propriedades da camada; no manual da 4.x aparece ainda "the layer contextual menu", isto é, botão direito na camada ► Filter…).
- Ele define "a subset of the features in the layer using a SQL-like WHERE clause". "As long as the query is active, only the features corresponding to its result are available in the project." Ou seja: o filtro ESCONDE do projeto tudo o que não atende; as outras feições continuam no arquivo, mas somem do mapa, da tabela e das contagens até o filtro ser removido.
- No painel Layers, a camada filtrada ganha um ícone de filtro (funil) ao lado do nome; passar o mouse mostra a consulta; duplo clique no ícone reabre o Query Builder.
- A tela tem as listas Fields (campos; duplo clique põe o nome na consulta), Values (botões **Sample**, com os 25 primeiros valores únicos, e **All**, com todos) e Operators.
- Manual da 4.x: "The filter is made at the data provider (OGR, GeoPackage, PostgreSQL, MS SQL Server…) level. So the syntax depends on the data provider" (exemplo dado: ILIKE não é aceito em GeoPackage).

### `qgis-ferramentas-gerais` — QGIS User Guide 3.44, "General Tools" (já criada na 08-02). URL: https://docs.qgis.org/3.44/en/docs/user_manual/introduction/general_tools.html (igual na 4.x)

- "attribute table and map canvas show the same information, so if you select one feature in the attribute table, it will be selected on the map canvas too".
- Painel **Statistics** (Ctrl+6): resumo de um campo de uma camada vetorial (contagem, soma, média…), para a camada toda ou só para as feições selecionadas ("Selected features only").
- **Show Feature Count** no menu de contexto da camada.

### `qgis-tabela-atributos` — QGIS User Guide 3.44, "Working with the Attribute Table" (já criada na 08-02).
- O título da tabela mostra o total de feições e quantas estão selecionadas/filtradas.
- Lista no canto inferior esquerdo: Show All Features, Show Selected Features (igual a abrir com Shift+F6).
- **Field Calculator** (botão na tabela, Ctrl+I): cria um campo novo ou atualiza um existente com o resultado de uma expressão. (Só cite que existe e que ele ALTERA dados; usar é assunto da lição 08-05. Não ensine a usar.)

### `qgis-expressoes` — QGIS User Guide 3.44, "Expressions". URL: https://docs.qgis.org/3.44/en/docs/user_manual/expressions/expression.html (igual na 4.x)
- Aspas: "single quotes return a literal, so a text placed between single quotes ('145') is interpreted as a string. Double quotes will give you the value of that text so use them for fields ("myfield"). Fields can also be used without quotes (myfield). No quotes for numbers (3.16)."

### `qgis-funcoes` — QGIS User Guide 3.44, "List of functions". URL: https://docs.qgis.org/3.44/en/docs/user_manual/expressions/functions_list.html (igual na 4.x)
- `$length`: "Returns the length of a linestring. […] The length calculated by this function respects both the current project's ellipsoid setting and distance unit settings. For example, if an ellipsoid has been set for the project then the calculated length will be ellipsoidal, and if no ellipsoid is set then the calculated length will be planimetric."
- `length(geometry)`: "Calculations are always planimetric in the Spatial Reference System (SRS) of this geometry, and the units of the returned length will match the units for the SRS."
- Consequência (minha, coberta pelas duas frases): numa camada em graus (4674 ou 4326), `length(@geometry)` devolve graus, não metros; numa camada em UTM (31980), devolve metros no plano da projeção. NÃO escreva `$geometry`/`@geometry` sem necessidade: se precisar citar, use `length($geometry)` só como exemplo de "a outra função"; o foco é `$length`.

## Conceitos que a lição deve deixar claros

- Expressão = uma pergunta de sim ou não feita a cada feição: campo, operador, valor. Campo entre aspas duplas, texto entre aspas simples, número sem aspas. Operadores usados: `=`, `<>`, `>`, `<`, `AND`, `OR`, `IS NULL`.
- **Selecionar** (Select Features By Expression, Ctrl+F3): marca as feições que atendem; as outras continuam no mapa e na tabela. A contagem aparece no título da tabela. Serve para olhar, conferir, exportar só as selecionadas.
- **Filtrar** (Layer ► Filter…): esconde do projeto as que não atendem, até tirar o filtro. O funil ao lado da camada avisa. Risco: esquecer o filtro ligado e achar que "sumiram postes", ou entregar uma contagem de camada filtrada como se fosse o total.
- Nenhum dos dois altera o arquivo. Quem altera é a edição e a calculadora de campo (lição 08-05).
- Contar: título da tabela de atributos (total, filtradas, selecionadas); Show Feature Count; painel Statistics (Ctrl+6) para soma/média de um campo, com "Selected features only".
- Texto tem de ser igual ao que está gravado: `'madeira'` não acha `'Madeira'` (NÃO afirme nada sobre maiúsculas/minúsculas de cada formato: diga só "escreva o valor igual ao que aparece na lista Values; use o botão All para ver os valores que existem").
- Caminhos iguais na 3.44 e na 4.x; diferença: na 4.x o manual cita Filter… também no menu de contexto da camada.

## Questões: ideias (situações de trabalho; todas dentro da lição)

- O colega reclama que "sumiram postes" da camada: o que olhar primeiro (funil/filtro ligado).
- Quero destacar no mapa os postes com mais de 5 ocupantes sem esconder os outros: filtrar ou selecionar?
- Expressão certa para achar os pontos de fixação sem plaqueta (aspas duplas no campo, simples no texto) × erros de aspas.
- Contagem entregue com filtro ligado: qual o erro.
- `$length` × `length`: qual respeita o elipsoide do projeto; o que `length` devolve numa camada em graus.
- Campo `compr_proj_m` × comprimento da geometria: por que podem discordar e em qual confiar para conferir (a geometria mede o desenho; o campo é digitado) — sem dizer qual "vale" no contrato: `{{confirmar}}`.
- Onde ler quantas feições foram selecionadas.
- A expressão não achou nada porque o valor foi escrito diferente do gravado: o que fazer (lista Values ► All).
- `"fibras" IS NULL` × `"fibras" = 0`: valor vazio não é zero (os 2 cabos metálicos têm `fibras` vazio).
