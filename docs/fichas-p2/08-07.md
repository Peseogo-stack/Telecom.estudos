## Fontes

### `qfield-comecar` — QField Documentation, "Get started" (documentacao; organização: OPENGIS.ch / QField). URL: https://docs.qfield.org/get-started/ (acesso em 11/11/2026)
- Os 5 passos: 1. instalar o QField ("available for Android, iOS, Windows, macOS and Linux"); 2. preparar o projeto no QGIS: "Install the QFieldSync plugin in QGIS and use it to "package" your project so it can be opened in QField"; 3. levar o projeto para o aparelho, por cabo/cópia local ou pelo QFieldCloud ("sync your project automatically between your team and your devices"); 4. coletar em campo; 5. trazer as mudanças de volta, "over cable, or automatically if you used QFieldCloud".

### `qfield-qfieldsync` — QField Documentation, tutorial "QFieldSync" (documentacao). URL: https://docs.qfield.org/get-started/tutorials/get-started-qfs/ (há versão em português em https://docs.qfield.org/pt/get-started/tutorials/get-started-qfs/; acesso em 11/11/2026)
- QFieldSync "is the QGIS plugin used to package your projects for QField". Ele: empacota o projeto num formato que o QField lê; cria mapas de fundo (basemaps); "Sets project layers to Offline editing by default"; "Synchronizes changes made in the field back to the desktop project".
- Fluxo típico: criar o pacote como cópia de trabalho numa pasta separada → copiar a pasta para o aparelho → coletar em campo com o QField → copiar a pasta modificada de volta para o computador → sincronizar com o projeto do QGIS.
- Instalar: no QGIS, **Plugins > Manage and Install Plugins...**, procurar "QFieldSync" e **Install Plugin**.
- Ação de cada camada no pacote (configuração do projeto): **Copy** (copia a camada sem acompanhar mudanças); **Offline editing** ("Copies the layer into the packaged project folder and tracks changes in a changelog database. When synchronizing changes back to the desktop project, QFieldSync applies recorded changes to the original source layer."); **Remove** (deixa a camada fora do pacote); e outras duas que a lição não precisa citar.
- Aviso do tutorial: "If a GeoPackage contains multiple layers, QFieldSync packages all layers in that file even if only one layer is included in the QGIS project." (Importa para dados da empresa: o arquivo inteiro vai junto.)
- **Area of Interest**: ao empacotar, dá para escolher uma área; "QFieldSync exports only features intersecting that area of interest".
- **Basemap**: "A basemap is a raster layer added as the bottom layer of the packaged project file. When working offline with QField, add a raster layer or configure a map theme as a basemap." "Prepare offline layers on desktop before starting fieldwork."
- **Permissions** (propriedades da camada para o QField): dá para desligar adicionar feições, apagar feições, editar atributos ou mexer na geometria.
- Empacotar: **Plugins > QFieldSync > Package for QField**. Depois, copiar a pasta exportada para o aparelho.
- "Save your QGIS project using the standard Save As... command in QGIS because you will re-open this desktop project later to synchronize field changes."
- Trazer de volta: abrir o projeto original no QGIS, copiar a pasta modificada do aparelho para o computador e usar **Plugins > QFieldSync > Synchronize from QField**.
- "Synchronize field changes back to your desktop project only once per export. To collect additional data in the field, create a new QField package to prevent synchronization conflicts or duplicate features."

## O que a lição deve deixar claro (tudo coberto acima)

- O ciclo: preparar e empacotar no QGIS (QFieldSync) → copiar para o aparelho → coletar sem internet → copiar de volta → sincronizar UMA vez → para nova coleta, novo pacote.
- Para trabalhar sem internet, o mapa de fundo e as camadas offline são preparados ANTES, no computador.
- "Offline editing" é o que faz as mudanças de campo voltarem para a camada original; "Copy" leva a camada só para consulta.
- A sincronização mexe na camada original: vale tudo o que a lição 08-05 disse sobre cópia de segurança e sobre quem pode editar o cadastro. `{{confirmar}}`
- Duas formas de transporte: cabo/cópia local, ou QFieldCloud (sincronização automática entre equipe e aparelhos). Qual a empresa usa, se usa: `{{confirmar}}`.
- O SRC e os campos são os do projeto do QGIS: o que foi mal definido no computador chega mal definido no campo (remeta às lições 08-03 e 08-02, sem afirmar nada novo sobre o QField).
- O que coletar numa vistoria de postes (foto, código do poste, o que viu) é assunto das lições do módulo 7; aqui só o ciclo.

## Termos de glossário novos

`qfield` (aplicativo de coleta em campo que abre projetos do QGIS), `qfieldsync` (complemento do QGIS que empacota o projeto para o QField e traz as mudanças de volta), `empacotar` (só se a lição usar como termo), `mapa-de-fundo` (basemap: camada raster posta no fundo do projeto; para uso sem internet, é preparada antes).

## Diagrama `ciclo-qfield`

Um ciclo com 5 passos em volta: "1. QGIS: preparar o projeto e empacotar (QFieldSync ► Package for QField)" → "2. Copiar a pasta para o aparelho" → "3. Campo: coletar com o QField, sem internet" → "4. Copiar a pasta de volta" → "5. QGIS: Synchronize from QField (uma vez por pacote)" → volta ao 1 com "nova coleta = novo pacote". No centro ou embaixo: "Mapa de fundo e camadas offline são preparados antes, no computador."

## Questões: ideias (situações)

- Cheguei ao campo sem internet e o mapa de fundo não aparece: o que faltou fazer antes.
- Coletei, sincronizei, e no dia seguinte voltei a campo com o MESMO pacote e sincronizei de novo: qual o risco (conflito ou feição duplicada; uma sincronização por pacote).
- Quero que o colega só consulte os postes no celular, sem alterar: que ação/permissão usar (Copy; ou Permissions desligando edição).
- Quero que os pontos coletados voltem para a camada original: que ação (Offline editing).
- O projeto usa só a camada `postes` de um GeoPackage com 5 camadas: o que vai no pacote (todas as camadas do arquivo).
- O chefe pede para levar o cadastro real no meu celular pessoal: o que fazer antes (confirmar com a empresa/TI).
- Em que programa se faz o empacotamento e em qual a coleta.
- Depois de sincronizar, um poste apareceu no lugar errado: onde está a origem provável do problema e que cuidado da 08-05 protegia (cópia de segurança antes de sincronizar).
