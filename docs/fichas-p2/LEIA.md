# Fichas de fatos das lições de QGIS e postes (P2)

Branch de trabalho `fichas-p2`. Não vai para o main.

Cada ficha traz o que foi conferido na fonte para uma lição: o trecho de cada fonte, os números do exercício conferidos no arquivo fictício, os cuidados e as ideias de questão. `INSTRUCOES-LICAO.md` é o roteiro que o agente de redação segue. A lição é escrita a partir da ficha e depois revisada frase a frase contra ela.

O estado de cada lição (fechada ou não) está em `docs/estado-trabalho.md`, no main.
