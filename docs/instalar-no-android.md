# Instalar no Android e usar sem internet

Endereço do app: **https://peseogo-stack.github.io/Telecom.estudos/**

## Instalar (uma vez, com internet)

1. Abra o endereço no **Chrome** do celular.
2. Espere a tela **Hoje** carregar. Quando aparecer o aviso "Pronto: o app agora funciona sem internet", ele já guardou tudo.
3. Toque no menu **⋮** (três pontos, no canto de cima) ► **Instalar app**. Em algumas versões o item se chama **Adicionar à tela inicial** ► **Instalar**.
   - Se o Chrome mostrar uma faixa "Instalar Fibra em Campo" embaixo, pode tocar nela.
   - Também dá para instalar em **Ajustes ► Instalar e usar sem internet ► Instalar no aparelho**, quando o Chrome oferecer.
4. O ícone **Fibra em Campo** aparece na tela inicial. Abra por ele: o app ocupa a tela inteira, sem a barra do navegador.

## Conferir que funciona sem internet

1. Com o app aberto, passeie uma vez pelas telas (Trilha, uma lição, Ferramentas).
2. Ligue o **modo avião**.
3. Feche o app e abra de novo pelo ícone. Tudo deve abrir: lições, questões, revisão, ferramentas, glossário e caderno.

## Atualizações

- Quando sair uma versão nova e você estiver com internet, aparece **"Nova versão disponível"** ► toque em **Atualizar**.
- Seu progresso e o caderno ficam no aparelho e **não se perdem** na atualização.

## Cuidados

- Os dados ficam **só neste aparelho** (progresso, revisão, caderno). Limpar os dados do Chrome ou desinstalar o app apaga tudo.
- Faça cópia em **Ajustes ► Cópia de segurança ► Exportar tudo** de vez em quando. O arquivo pode ter informações da empresa: guarde só com você.
- Para levar o caderno do PC para o celular: **Meu caderno ► Exportar caderno** no PC, envie o arquivo para você mesmo e use **Importar arquivo** no celular.
